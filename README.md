# 🎓 Udemy Clone Website

Hii Everyone! 👋

Welcome to my **Udemy Clone Website** project. This project is a front-end recreation of the popular online learning platform **Udemy**, built entirely using **HTML5** and **CSS3**. It focuses on creating an attractive, responsive, and user-friendly learning platform interface.

---

## 📌 Project Overview

This project replicates the look and feel of the Udemy homepage with a clean and modern design. It demonstrates fundamental front-end development concepts such as responsive layouts, navigation design, course card creation, and structured webpage sections.

The project helped me strengthen my understanding of **HTML structure**, **CSS styling**, **Flexbox**, **Grid layouts**, **hover effects**, and **responsive web design principles**.

---

## ✨ Features

✅ Responsive Navigation Bar
✅ Hero Section with Attractive Banner
✅ Course Categories Section 📚
✅ Featured & Trending Course Cards ⭐
✅ Hover Effects and Interactive UI 🎨
✅ Clean and Modern User Interface 💻
✅ Fully Responsive Design 📱
✅ Footer with Useful Links 🔗

---

## 🛠️ Technologies Used

* 🌐 HTML5
* 🎨 CSS3
* 📱 Responsive Web Design
* ✨ CSS Animations & Hover Effects

## 🎯 Purpose of the Project

The main objective of this project is to practice and improve my front-end web development skills by recreating a real-world website interface. Through this project, I gained hands-on experience in:

* Structuring webpages using HTML
* Styling modern interfaces with CSS
* Creating responsive layouts
* Improving UI/UX design skills
* Building reusable web components
